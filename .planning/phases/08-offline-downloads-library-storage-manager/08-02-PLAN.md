# Plan 08-02: Offline Playback Resolver in AudioHandler & Downloads Riverpod Providers

## Objective
Integrate offline-first playback resolution in `TarneemnaAudioHandler` so that downloaded hymns play instantly from the local file system without buffering, and expose Riverpod providers for the offline downloads library and storage manager.

## Proposed Tasks
1. **Task 08-02-01: Offline-First Playback Resolver in TarneemnaAudioHandler**
   - In `skipToQueueItem(int index)`:
     - Check if item is stored locally via `OfflineStorageService`.
     - If local file exists, call `_player.setFilePath(localPath)` instead of network `setUrl`.
     - Populate media item metadata with offline flag.
2. **Task 08-02-02: Downloads & Storage Riverpod Providers**
   - Create `lib/features/downloads/presentation/providers/download_providers.dart`:
     - `offlineStorageServiceProvider`
     - `downloadManagerServiceProvider`
     - `downloadedHymnsListProvider`
     - `downloadProgressMapProvider`
     - `storageUsageBytesProvider`
3. **Task 08-02-03: Quality Gates**
   - Run `flutter analyze lib/features/downloads/`.
