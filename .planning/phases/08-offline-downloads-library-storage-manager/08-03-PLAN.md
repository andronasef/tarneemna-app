# Plan 08-03: Offline Downloads Library UI, Storage Manager Screen & Unit Tests

## Objective
Build the Offline Downloads Library screen, Storage Manager breakdown and batch cleanup view, and comprehensive unit tests.

## Proposed Tasks
1. **Task 08-03-01: Offline Downloads Library Screen**
   - Create `lib/features/downloads/presentation/screens/offline_downloads_screen.dart`:
     - Displays all downloaded hymns with thumbnail, title, singer, file size (MB), and duration.
     - Search filter: offline instant search in title, singer, and lyrics.
     - Play all / Shuffle all offline hymns.
     - Swipe-to-delete or popup menu delete.
     - Tap to play via `TarneemnaAudioHandler`.
2. **Task 08-03-02: Storage Manager Screen**
   - Create `lib/features/downloads/presentation/screens/storage_manager_screen.dart`:
     - Clean visual breakdown: Total app storage, Hymns downloaded, Metadata/Cache.
     - Batch selection mode to delete multiple files.
     - One-tap "مسح كافة الترانيم المحملة" with confirmation dialog.
3. **Task 08-03-03: Navigation Route & Unit Tests**
   - Register `/downloads` and `/storage` in `lib/core/routes.dart`.
   - Add unit tests in `test/features/downloads/offline_storage_test.dart`.
   - Run `flutter test` and `flutter analyze`.
