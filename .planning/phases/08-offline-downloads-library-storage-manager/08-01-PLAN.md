# Plan 08-01: Offline Storage Entity, Hive Download Box & Download Service

## Objective
Implement `DownloadedHymn` model, local download file storage manager, Hive registry box, and the background download engine supporting progress tracking and cancellation.

## Proposed Tasks
1. **Task 08-01-01: DownloadedHymn Entity & Local Storage Registry**
   - Create `lib/features/downloads/domain/entities/downloaded_hymn.dart`:
     - Fields: `id`, `title`, `singer`, `album`, `artworkUrl`, `localFilePath`, `fileSizeBytes`, `downloadedAt`, `lyrics`, `source`.
     - Conversion methods to/from JSON map for Hive.
     - Helper method `toHymn()`.
   - Create `lib/features/downloads/data/sources/offline_storage_service.dart`:
     - Opens Hive box `downloaded_hymns`.
     - Provides `getDownloadedHymns()`, `getDownloadedHymn(String id)`, `saveDownloadedHymn(DownloadedHymn hymn)`, `deleteDownloadedHymn(String id)`, `clearAll()`.
     - Calculates total storage consumed in bytes.
2. **Task 08-01-02: Download Manager Service**
   - Create `lib/features/downloads/data/sources/download_manager_service.dart`:
     - Streams download progress per track (`Map<String, double> progressStream`).
     - Downloads Taranim Arabia MP3 or YouTube stream directly to app documents directory.
     - Saves completed track metadata to `offlineStorageService`.
3. **Task 08-01-03: Quality Gates**
   - Run `flutter analyze lib/features/downloads/`.
