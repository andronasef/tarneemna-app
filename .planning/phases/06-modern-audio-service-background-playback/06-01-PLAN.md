# Plan 06-01: Audio Service Dependencies, Android Configuration & Core AudioHandler

## Objective
Add `audio_service` and `audio_session` to `pubspec.yaml`, configure Android permissions & service declarations in `AndroidManifest.xml` and `MainActivity.kt`, and implement the foundation `TarneemnaAudioHandler`.

## Proposed Tasks
1. **Task 06-01-01: Add Dependencies**
   - Add `audio_service: ^0.18.12` and `audio_session: ^0.1.21` to `pubspec.yaml`.
   - Run `flutter pub get`.
2. **Task 06-01-02: Configure Android Native Layer**
   - Update `android/app/src/main/AndroidManifest.xml`:
     - Add `FOREGROUND_SERVICE_MEDIA_PLAYBACK` permission.
     - Add `com.ryanheise.audioservice.AudioService` service declaration with `foregroundServiceType="mediaPlayback"`.
     - Add `com.ryanheise.audioservice.MediaButtonReceiver`.
   - Update `android/app/src/main/kotlin/com/example/traneemna/MainActivity.kt`:
     - Change base class to `AudioServiceActivity`.
3. **Task 06-01-03: Implement TarneemnaAudioHandler**
   - Create `lib/features/audio/data/sources/tarneemna_audio_handler.dart`:
     - Extends `BaseAudioHandler` with `QueueAudioHandler` and `SeekHandler`.
     - Wraps `AudioPlayer` from `just_audio`.
     - Initializes `AudioSession` for audio focus management.
     - Maps `AudioPlayer` events (`playerStateStream`, `positionStream`, `playbackEventStream`) to `PlaybackState`.
     - Implements `play()`, `pause()`, `stop()`, `seek(position)`.
   - Verify with `flutter analyze lib/features/audio/`.
