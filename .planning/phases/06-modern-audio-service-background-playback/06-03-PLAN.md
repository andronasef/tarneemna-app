# Plan 06-03: Sleep Timer, A-B Repeat Loop, Player Bridge & Unit Tests

## Objective
Implement practice tools (A-B Repeat loop), utility features (Sleep Timer with preset intervals and "end of current track"), migrate the legacy `Player` class to bridge to `AudioHandler`, and implement unit tests.

## Proposed Tasks
1. **Task 06-03-01: Sleep Timer Service & Provider**
   - Create `lib/features/audio/domain/services/sleep_timer_service.dart`:
     - Presets: 15 mins, 30 mins, 45 mins, 60 mins, custom duration, and `endOfTrack`.
     - Periodic 1-second countdown ticker.
     - Smooth volume ramp-down before pausing audio upon timer expiration.
     - Creates `sleepTimerNotifierProvider` for UI consumption.
2. **Task 06-03-02: A-B Repeat Loop Controller & Provider**
   - Create `lib/features/audio/domain/services/ab_repeat_controller.dart`:
     - Stores `pointA` and `pointB` (Durations).
     - Validates point ordering (point B must be after point A).
     - Subscribes to position stream: when position >= pointB, seeks back to pointA.
     - Exposes methods: `setPointA()`, `setPointB()`, `clear()`.
     - Creates `abRepeatNotifierProvider`.
3. **Task 06-03-03: Legacy Player Bridge & App Entrypoint**
   - Update `lib/player.dart` so calls to `Player.playHymn`, `Player.pause`, `Player.stop`, etc. delegate directly to the singleton `AudioHandler`.
   - Update `lib/main.dart` to initialize `AudioService` and inject the `AudioHandler` into `ProviderScope`.
4. **Task 06-03-04: Unit Tests & Quality Verification**
   - Create `test/features/audio/audio_queue_test.dart` and `test/features/audio/sleep_timer_test.dart`.
   - Run `flutter test` and `flutter analyze`.
