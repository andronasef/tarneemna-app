# Plan 06-02: Audio Queue, Continuous Autoplay & Riverpod Playback Providers

## Objective
Implement queue management (Up Next) with reordering, automatic track progression (continuous autoplay), crossfade/gapless playback support, and full Riverpod integration.

## Proposed Tasks
1. **Task 06-02-01: Queue Management & Autoplay in AudioHandler**
   - Enhance `TarneemnaAudioHandler` to maintain `List<MediaItem>` queue.
   - Implement `addQueueItem(MediaItem item)`, `addQueueItems(List<MediaItem> items)`, `removeQueueItemAt(int index)`, `moveQueueItem(int oldIndex, int newIndex)`.
   - Implement `skipToNext()` and `skipToPrevious()`.
   - Implement automatic transition to the next hymn upon track completion.
   - Support `playHymn(Hymn hymn)` and `playQueue(List<Hymn> hymns, {int startIndex = 0})`.
2. **Task 06-02-02: Riverpod Audio & Queue Providers**
   - Create `lib/features/audio/presentation/providers/audio_providers.dart`:
     - `audioHandlerProvider`: provides the initialized `TarneemnaAudioHandler`.
     - `playbackStateStreamProvider`: streams current `PlaybackState`.
     - `currentMediaItemStreamProvider`: streams current `MediaItem`.
     - `audioQueueStreamProvider`: streams current `List<MediaItem>`.
     - `audioPositionStreamProvider`: streams current position `Duration`.
     - `audioBufferedPositionStreamProvider`: streams buffered position `Duration`.
     - `audioDurationStreamProvider`: streams track duration `Duration?`.
     - `isPlayingProvider`: derived boolean for play/pause state.
3. **Task 06-02-03: Verify Codebase Quality**
   - Run `flutter analyze lib/features/audio/`.
