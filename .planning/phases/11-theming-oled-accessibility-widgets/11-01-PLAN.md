# Plan 11-01: Settings Service, Theme Models & Riverpod State

## Objective
Implement models, Hive storage service, and Riverpod notifiers for application settings including Theme Mode (Light, Dark, OLED Pitch Black), Spiritual Accent Palettes, and Senior Accessibility Font Scaling.

## Proposed Tasks
1. **Task 11-01-01: Theme & Settings Data Models**
   - Create `lib/features/settings/domain/models/app_settings.dart`:
     - `AppThemeMode` enum: `system`, `light`, `dark`, `oled`.
     - `SpiritualAccent` enum: `coral` (Tarneemna), `sky` (Celestial), `gold` (Holy Gold), `purple` (Royal), `olive` (Olive Branch).
     - `AppSettings` immutable class with `copyWith`, `toMap`, `fromMap`.
2. **Task 11-01-02: Hive Settings Service**
   - Create `lib/features/settings/data/sources/settings_service.dart`:
     - Open box `app_settings`.
     - Read and save `AppSettings`.
3. **Task 11-01-03: Riverpod State Notifier**
   - Create `lib/features/settings/presentation/providers/settings_providers.dart`:
     - `settingsServiceProvider`.
     - `settingsNotifierProvider` (StateNotifier managing `AppSettings`).
     - Derived `themeDataProvider` returning dynamic `ThemeData` based on theme mode, spiritual accent, and font scale.
4. **Task 11-01-04: Unit Testing**
   - Create `test/features/settings/settings_test.dart` testing serialization, default values, and theme data construction.
