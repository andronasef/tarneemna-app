# Plan 11-02: Settings Screen UI & Senior Accessibility Typography Controls

## Objective
Build a comprehensive, modern, Arabic-first Settings screen allowing users to customize theme mode (including OLED Black), choose spiritual accent palettes, adjust senior font scaling, and configure offline/audio preferences.

## Proposed Tasks
1. **Task 11-02-01: Build Settings Screen**
   - Create `lib/features/settings/presentation/screens/settings_screen.dart`:
     - Theme selector: System, Light, Dark, OLED Black (with battery saver tag).
     - Spiritual Color Accent picker with colored circular swatches.
     - Senior Accessibility font scaling slider / segment buttons with live preview text ("يا صاحب الحنان").
     - Audio preferences: Gapless playback, Crossfade toggle, Auto-download favorites on Wi-Fi.
     - App info & About section.
2. **Task 11-02-02: Route Registration & Header Link**
   - Register `/settings` route in `lib/core/routes.dart`.
   - Add Settings icon button in `DiscoveryHeaderSection` or Home app bar.
