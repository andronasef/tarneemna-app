# Plan 11-03: Dynamic Root Theming, Global Text Scaling & Android Widget Setup

## Objective
Wire the reactive theme and global font scaler into `App` (`lib/app/app.dart`), initialize `SettingsService` in `main.dart`, and add Android App Widget template files for playback control.

## Proposed Tasks
1. **Task 11-03-01: Connect App to Riverpod Theme & TextScaler**
   - Update `lib/app/app.dart` to use `ConsumerWidget`:
     - Watch `settingsNotifierProvider` and `themeDataProvider`.
     - Apply `builder: (context, child) => MediaQuery(data: MediaQuery.of(context).copyWith(textScaler: TextScaler.linear(settings.fontScale)), child: child!)`.
2. **Task 11-03-02: Initialize SettingsService in main.dart**
   - Initialize `SettingsService` during startup before `runApp`.
   - Provide override in `ProviderScope`.
3. **Task 11-03-03: Android Widget Configuration**
   - Add AppWidget XML layout (`android/app/src/main/res/layout/tarneemna_widget.xml`) with playback control buttons.
   - Add AppWidgetProvider XML metadata (`android/app/src/main/res/xml/tarneemna_widget_info.xml`).
   - Register receiver in `android/app/src/main/AndroidManifest.xml`.
4. **Task 11-03-04: Full Verification**
   - Run `flutter analyze` and `flutter test`.
