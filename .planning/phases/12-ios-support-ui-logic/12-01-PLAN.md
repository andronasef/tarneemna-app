# Plan 12-01: Native iOS Scaffolding, SwiftPM & Info.plist Configuration

## Objective
Generate the native iOS runner project for Tarneemna using Flutter's modern Swift Package Manager (SwiftPM) toolchain (default in Flutter 3.44+), configure `Info.plist` with required background audio modes, streaming ATS rules, and localized permissions, and generate the iOS native splash screen.

## Proposed Tasks
1. **Task 12-01-01: Scaffold Native iOS Runner with SwiftPM**
   - Run `flutter create . --platforms=ios --org com.increase` to generate standard modern `ios/` workspace files (`Runner.xcodeproj`, `AppDelegate.swift`, etc.).
   - Verify bundle identifier matches `com.increase.tarneemna`.
   - Leverage Flutter 3.44's default Swift Package Manager (`enable-swift-package-manager: true`) without legacy CocoaPods dependencies whenever possible.

2. **Task 12-01-02: Configure Info.plist**
   - In `ios/Runner/Info.plist`:
     - Add `UIBackgroundModes` containing `<string>audio</string>` for lock-screen and background playback.
     - Add `NSAppTransportSecurity` with `NSAllowsArbitraryLoads: true` for HTTP streaming of Taranim Arabia MP3s.
     - Add privacy descriptions:
       - `NSMicrophoneUsageDescription`: "يستخدم التطبيق الميكروفون للبحث الصوتي عن الترانيم."
       - `NSSpeechRecognitionUsageDescription`: "يستخدم التطبيق التعرف على الصوت للبحث الصوتي عن الترانيم."
       - `NSPhotoLibraryAddUsageDescription`: "لحفظ بطاقات اقتباسات الترانيم في معرض الصور."
     - Set `CFBundleDisplayName` to `ترنيمنا`.
     - Set `CFBundleLocalizations` to support `ar` (Arabic).

3. **Task 12-01-03: Configure iOS Native Splash Screen**
   - Update `pubspec.yaml` under `flutter_native_splash`: set `ios: true`.
   - Run `dart run flutter_native_splash:create` to update `LaunchScreen.storyboard` and iOS launch image assets.
