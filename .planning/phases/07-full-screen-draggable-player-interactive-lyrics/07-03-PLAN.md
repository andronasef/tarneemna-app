# Plan 07-03: Hymn Quote Card Generator & Timestamp Sharing

## Objective
Implement an aesthetic Hymn Quote Card generator allowing users to select lines of lyrics and share as an image card, plus timestamped playback audio sharing.

## Proposed Tasks
1. **Task 07-03-01: Quote Card Generator**
   - Create `lib/features/lyrics/presentation/widgets/quote_card_dialog.dart`:
     - Allows selecting lines from the hymn lyrics (checkboxes / line selection).
     - Gradient theme presets: Dark Velvet, Sunset Glow, Celestial Blue, Olive Gold.
     - `RepaintBoundary` rendering card with quotes, hymn title, singer, and "ترانيمنا" logo watermark.
     - Export & share using `share_plus`.
2. **Task 07-03-02: Timestamp Sharing Helper**
   - Create `lib/features/audio/domain/services/share_service.dart`:
     - Formats track title, singer, current position timestamp, and download link.
     - Opens system share sheet.
3. **Task 07-03-03: Unit & Widget Tests**
   - Create tests in `test/features/lyrics/lyrics_test.dart`.
   - Run `flutter test` and `flutter analyze`.
