# Plan 07-02: Interactive Lyrics Viewer & Sheet Music / Chords Modal

## Objective
Build an interactive lyrics viewer supporting text size adjustment, stanza reading mode, and a modal for viewing sheet music (نوتة موسيقية) and guitar chords (كوردات) fetched from Taranim Arabia.

## Proposed Tasks
1. **Task 07-02-01: Interactive Lyrics Sheet & Viewer**
   - Create `lib/features/lyrics/presentation/widgets/lyrics_bottom_sheet.dart`:
     - Displays full lyrics with Arabic RTL text direction and stanza formatting.
     - Font size control bar (`-` / `+` scaling font from 14pt to 28pt).
     - Copy lyrics button.
     - Button to open Hymn Quote Card generator.
2. **Task 07-02-02: Sheet Music & Chords Viewer**
   - Create `lib/features/lyrics/presentation/widgets/sheet_music_modal.dart`:
     - Shows buttons/options to open chord PDF or music note image in web viewer or external viewer if URLs exist.
3. **Task 07-02-03: Quality Gates**
   - Run `flutter analyze lib/features/lyrics/`.
