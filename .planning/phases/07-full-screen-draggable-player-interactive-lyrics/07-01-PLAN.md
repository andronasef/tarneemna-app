# Plan 07-01: Full-Screen Draggable Bottom-Sheet Player

## Objective
Build a Spotify-style draggable bottom-sheet player that transitions seamlessly from a compact mini player into a full-screen modern worship player with high-res artwork, seeker slider, speed selector, sleep timer dialog, and A-B repeat controls.

## Proposed Tasks
1. **Task 07-01-01: Build Full-Screen Player View**
   - Create `lib/features/audio/presentation/widgets/full_player_view.dart`:
     - Dismiss chevron to collapse back to mini player.
     - Large rounded album art with soft elevation.
     - Track title and singer with Arabic typography.
     - Smooth seeker bar with elapsed time and remaining duration.
     - Playback controls: Shuffle, Skip Previous, Play/Pause/Loading, Skip Next, Repeat mode.
     - Action toolbar: Speed button (bottom sheet selector), Sleep Timer button (dialog), A-B Repeat button (dialog/bar), Lyrics toggle button, Share button.
2. **Task 07-01-02: Upgrade MiniPlayer Widget**
   - Update `lib/screens/home/widgets/miniplayer.dart` or create `lib/features/audio/presentation/widgets/draggable_player.dart`:
     - Embeds `Miniplayer` with `minHeight: 68` and `maxHeight: MediaQuery.of(context).size.height`.
     - In mini state: thumbnail, title, artist, play/pause button, linear progress bar.
     - In expanded state: renders `FullPlayerView`.
     - Wire with Riverpod providers (`currentMediaItemStreamProvider`, `isPlayingProvider`, `audioPositionStreamProvider`).
3. **Task 07-01-03: Quality Gates**
   - Run `flutter analyze lib/features/audio/`.
