# Plan 09-03: Albums Catalog & Album Detail Tracklist Screen

## Objective
Build the Christian albums catalog screen with artwork grid and the album detail view with full tracklist and one-tap album playback.

## Proposed Tasks
1. **Task 09-03-01: Albums Catalog Screen**
   - Create `lib/features/albums/presentation/screens/albums_screen.dart`:
     - Grid of album covers with title, singer, and release year.
     - Search filter bar.
     - Tap opens `AlbumDetailScreen`.
2. **Task 09-03-02: Album Detail Screen**
   - Create `lib/features/albums/presentation/screens/album_detail_screen.dart`:
     - Album cover artwork, title, and artist header.
     - "تشغيل الألبوم" (Play full album in order) button.
     - Numbered tracklist with play and download actions.
3. **Task 09-03-03: Route Registration & Unit Tests**
   - Register `/singers`, `/singers/:id`, `/albums`, `/albums/:id` in `lib/core/routes.dart`.
   - Add unit tests in `test/features/discovery/discovery_test.dart`.
   - Run `flutter test` and `flutter analyze`.
