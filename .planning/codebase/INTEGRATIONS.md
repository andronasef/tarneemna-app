# External Integrations

**Analysis Date:** 2026-10-04

## Third-Party Services & Packages

1. **Firebase**:
   - `firebase_core`: Core platform initialization (`DefaultFirebaseOptions.currentPlatform`).
   - `firebase_analytics`: Event logging and screen tracking.
2. **YouTube Explode (`youtube_explode_dart`)**:
   - Performs hymn search on YouTube without API key limits.
   - Resolves stream manifest and audio stream URLs.
3. **Audio Playback (`just_audio`)**:
   - Audio session and streaming player engine.
4. **Download Manager (`flutter_downloader`)**:
   - Native Android background download manager service.
   - Communicates task progress via `IsolateNameServer`.
5. **Google Fonts (`google_fonts`)**:
   - Cairo Arabic font family dynamic loading.
