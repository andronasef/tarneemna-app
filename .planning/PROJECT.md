# Tarneemna App (ترانيمنا)

## What This Is

A Flutter mobile application designed for searching, streaming, reading lyrics, and downloading Arabic Christian hymns ("ترانيم"). It connects with YouTube Explode and Taranim Arabia (ترانيم عربية) to provide instant streaming, direct MP3 downloads, accurate synchronized lyrics, full albums, singers directory, and personal worship playlists.

## Core Value

Provide a seamless, spiritual, and uninterrupted worship listening experience both online and offline on modern mobile devices.

## Milestones

- **Milestone 1: Flutter Migration (Completed)**: Full modernization to Flutter 3.44.9 / Dart 3.12, declarative Android Gradle configuration, AndroidX compliance, and zero analyzer errors.
- **Milestone 2: Modern Player, Offline Library, Lyrics & Taranim Arabia Integration (In Progress)**:
  1. Full-screen draggable player (Spotify-like) with notification & lock screen controls (`audio_service`).
  2. Native Taranim Arabia integration (direct MP3s, full albums, singers directory, random hymn of the day).
  3. Interactive lyrics view with typography scaling and quote card sharing.
  4. Offline downloads library, storage manager, and batch album downloads.
  5. Dynamic home discovery screen, endless hymn radio, and singers catalog.
  6. Smart search (search by lyrics, recent searches, voice search) and personal library (favorites, playlists, history).
  7. Dark mode (OLED pitch black), custom accent themes, accessibility, and widgets.
